# 文献结构化比较与综述证据审查

> 本文件用于审查 [文献矩阵_Zotero.md](文献矩阵_Zotero.md) 中的 Zotero 输出，不等同于已完成的正式文献综述。所有没有 DOI 页面、PDF 正文或明确元数据支持的字段，均应在论文引用前再次核验。

## 1. 审查结论

`文献矩阵_Zotero.md` 保留了原始 Zotero 整理结果中的三类材料：

- 33 行比较矩阵（按标题去重后 30 篇）；
- 30 条逐篇结构化笔记（按标题去重后 28 篇）；
- 8 篇重点文献证据摘要。

因此，`文献矩阵_Zotero.md` 不能直接并入论文，也不能把其中所有“是/否”、算法名称、故障类型和实验结论视为已经核验的事实。

## 2. 数量与重复审查

比较矩阵共有 33 行记录，其中有 3 组明确重复；逐篇笔记共有 30 条，其中有 2 组明确重复：

| 材料 | 重复条目 | 处理建议 |
|---|---|---|
| 比较矩阵：第 11 行与第 19 行 | 合并为一条 |
| 比较矩阵：第 14 行与第 26 行 | 合并为一条 |
| 比较矩阵：第 16 行与第 29 行 | 合并为一条 |
| 逐篇笔记：第 11 条与第 19 条 | 合并为一条 |
| 逐篇笔记：第 14 条与第 26 条 | 合并为一条 |

按上述规则，矩阵得到 30 个唯一标题，逐篇笔记得到 28 个唯一标题。矩阵末尾的综述类文献和 RL 环境文献属于补充记录，不能与逐篇笔记编号直接对应。最终书目计数以 [唯一文献表_DOI核验.md](唯一文献表_DOI核验.md) 为准。

后续唯一文献计数应优先使用：

1. DOI 标准化值；
2. DOI 缺失时使用标题标准化值；
3. 标题相近但 DOI 不同的条目进行人工核验；
4. 同一文献的预印本、出版社页面和 PDF 只保留一个主记录。

## 3. 当前可直接使用的证据边界

### 3.1 可以作为初步背景证据的内容

- 机器与 AGV 在 FJSP 中存在加工和运输耦合关系；
- AGV 故障、机器故障、随机作业到达和订单变化会带来重调度需求；
- 异构图、图注意力、元路径和图 Transformer 可用于表达机器—工序关系；
- PPO、QMIX、DQN、actor–critic 和元启发式方法均被用于不同制造调度问题；
- 数字孪生和离散事件仿真可用于状态采集、事件注入和调度验证。

这些结论只能作为主题综述层面的表述，引用时仍需绑定到实际 DOI 或 PDF 证据。

### 3.2 当前不能直接写成论文事实的内容

- 某篇文献一定包含机器故障、AGV 故障和 JOB_ADD 的全部组合；
- 某篇文献一定使用 PPO、DQN、QMIX 或特定 GNN，若当前依据只有标题或二手摘要；
- “包含 AGV”必然等于“工序、机器和 AGV 由同一个联合动作同时决定”；
- “动态环境”必然等于故障、插单和在线事件；
- 某算法优于所有 PPO、QMIX、NSGA-II 或其他方法；
- 文献已报告满足特定在线决策时间约束；
- 本文方法或 transition 分组组相对优势更新在该问题中已经有直接先例；
- 不同论文的 makespan 数值可以跨数据集直接排名。

## 4. 全部纳入综述与分析标签

当前阶段不按“最接近本文”筛除文献。Zotero 输出中的候选文献暂时全部纳入综述素材、比较矩阵和主题分析范围。A、B、C 级只表示文献的研究相关性和可用于支撑的论断类型，不表示纳入或排除。

- A 级：问题结构或动态事件与本文较接近，可重点展开，但仍需逐篇核验；
- B 级：方法相关，可用于图表示、强化学习、异构图或策略优化背景；
- C 级：背景或邻近问题，可用于数字孪生、仿真、AGV 管理和研究脉络说明。

综述写作时应做到：

1. 所有唯一文献都保留在文献矩阵中；
2. 相关性较高的文献可以详细讨论，相关性较低的文献按主题合并概括；
3. 分类标签不能改变文献原本的问题设定，也不能把背景文献改写成本文问题的直接先例；
4. 明确重复条目合并为一个书目记录，但不丢失其可用证据；
5. “暂时全部纳入”不等于所有条目都已完成 DOI、全文和方法字段核验。

## 5. 需要优先核验的字段

### 5.1 书目信息

- 每条记录的 DOI 是否能解析到对应题目；
- 标题、作者、期刊、年份是否与 PDF 首页一致；
- 是否存在同题目不同版本、预印本和正式发表版重复；
- 没有 DOI 的条目不能因为标题看起来合理就补写 DOI。

### 5.2 方法字段

- PPO、DQN、QMIX、actor–critic 和 GRPO 必须以正文方法章节、算法框图或实验设置为依据；
- GNN、异构图、Petri 网和路径图需要区分，不能把所有图结构都写成 GNN；
- 三层编码、分阶段启发式编码和在线 RL 动作空间不是同一个概念；
- “多代理”可能表示多智能体 RL，也可能只是多个决策角色，必须看正文定义。

### 5.3 动态事件字段

- “动态环境”只能记录为动态环境，不能自动展开成机器故障、AGV 故障和 JOB_ADD；
- 资源增减、订单变化、随机到达、加工时间波动和故障应分别记录；
- 只有正文明确说明事件发生时间、分布或触发机制时，才可写入具体事件机制；
- “实时”应与报告的决策时间、重调度时间或在线约束分开记录。

### 5.4 实验字段

- 数据集、实例规模、训练/验证/测试划分、随机种子、重复次数和统计量应逐篇核验；
- 不同数据集上的 makespan 只可作方法设定背景，不能直接横向排名；
- 作者声称“优于基线”时，应保留比较范围、实例和评价指标，不能改写成普遍优越；
- 未报告标准差、置信区间或显著性检验时，应记录为“未报告”。

## 6. 与本文研究的可引用边界

本文可以谨慎使用现有材料支持以下背景性论断：

1. 加工资源和运输资源存在耦合，联合调度是一个独立的研究问题；
2. 机器故障、AGV 故障、随机到达和订单变化会使静态排程需要重调度；
3. 图表示能够提供表达工序、机器及其关系的建模方式；
4. 强化学习和多智能体强化学习已被用于部分动态制造调度问题；
5. 数字孪生和离散事件仿真可用于动态状态采集与调度验证。

现有材料不能直接支持以下结论：

- 本文方法优于 PPO、QMIX、DQN 或 NSGA-II；
- transition 分组的组相对优势更新已经被同类文献验证；
- 某一篇文献已经同时覆盖本文的多 AGV、机器故障、AGV 故障、JOB_ADD、工厂路网、三阶段动作、基础场景—动态事件场景和退化指标；
- 本文的 $C_{\max}$、$\Delta C_{\max}$ 和 $D_{C_{\max}}$ 已经被现有文献作为统一评价协议采用。

最后一项只能表述为：**当前检索证据尚未确认直接先例**，不能表述为绝对不存在相关研究。

## 7. 推荐的后续整理顺序

1. 从 Zotero 导出包含 DOI、标题、作者、年份、摘要和附件路径的 CSV 或 BibTeX；
2. 以 DOI 为主键重新去重；
3. 暂时保留全部唯一文献，逐篇核对其 PDF 首页、摘要、方法和实验章节；
4. 将“已核验事实”和“待核验字段”分列保存；
5. 按 A/B/C 标签分配综述篇幅，但不据此删除文献；
6. 再生成最终文献矩阵和综述；
7. 最后才把真实 DOI 引用插入论文第 1、2 章。

在完成第 1—4 步之前，文献矩阵中的字段只能作为写作素材，不能作为论文定稿依据。
