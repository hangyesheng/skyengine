# 论文术语规范与正文重构计划

本文件约束论文正文的学术表述。代码、实验归档和附录可以保留实现名称，正文优先使用问题定义、状态转移和评价指标的概念名称。

## 术语统一

| 工程或代码用语 | 论文正文用语 |
|---|---|
| clean | 基准场景（不注入外生动态事件） |
| uncertain | 动态事件场景（注入预生成事件时间线） |
| clean/uncertain 配对 | 基准场景—动态事件场景配对 |
| PacketFactory、SkyEngine | 本文仿真平台；第 3 章首次出现时说明实现名称 |
| GraphGRPOAgent | 本文方法；正文使用“基于关系图与组相对优势策略优化的加工—物流协同调度方法”，实现标识仅在复现实验说明中出现 |
| HGS-adapted | HGS 适配实现 |
| 早期图策略版本 | 受控消融或历史实现，不列为主方法基线 |
| `JOB_ADD` | 新作业到达事件 |
| `MACHINE_FAIL` | 机器故障事件 |
| `AGV_FAIL` | AGV 故障事件 |
| `env_timeline` | 仿真时间轴 |
| `step`、`action_space`、`bootstrap` | 环境步进、动作生成和初始化过程 |
| JSONL、CSV、YAML、命令行参数 | 实验记录格式或配置细节；正文不展开 |

基准场景和动态事件场景的完工时间分别记为

$$
C_{\max}^{\mathrm{base}},\qquad C_{\max}^{\mathrm{event}}.
$$

配对差值和相对退化定义为

$$
\Delta C_{\max}=C_{\max}^{\mathrm{event}}-C_{\max}^{\mathrm{base}},
\qquad
D_{C_{\max}}=\frac{\Delta C_{\max}}{C_{\max}^{\mathrm{base}}}.
$$

当动态事件包含新作业到达时，结果称为“动态事件下的综合性能”，不把全部差值解释为故障恢复能力。

## 正文重构顺序

1. 第 1 章只保留研究背景、研究问题、研究内容和贡献边界，不列出代码接口或工程验证步骤。
2. 第 2 章按“加工—运输协同、动态调度、图强化学习、仿真验证”组织相关工作；HGS 作为最接近的外部方法之一，不作为全文唯一参照。
3. 第 3 章描述平台的实体模型、状态转移、事件机制、算法接入和过程记录，删除命令行、脚本路径、类名和文件格式细节。
4. 第 4 章使用“基于关系图与组相对优势策略优化的加工—物流协同调度方法”作为正式名称，主体简称“本文方法”。实现标识 GraphGRPOAgent 只放在复现实验说明中，并准确说明当前更新规则是组相对优势策略优化实现，不直接声称等同于标准 GRPO。
5. 第 5 章主对比只保留 OR-Tools、HGS 适配实现和本文方法；PPO 风格更新、固定编码器、去关系图状态、时间惩罚奖励和固定 AGV 选择均放入消融或附加分析。
6. 第 5 章用“基准场景”“动态事件场景”“机器故障场景”“AGV 故障场景”“新作业到达场景”替代代码预设名称，表格列名也同步修改。
7. 研究问题采用三段式结构：基础调度质量、动态事件适应、机制消融与效率分析；不再使用 Q1—Q5 的编号串联全文。

## 主对比和消融边界

主对比回答本文方法相对于一个优化基线和一个外部图调度适配方法的表现。OR-Tools 结果表述为给定时间限制下的可行解或最佳已知解；HGS 结果表述为 HGS 适配实现；本文方法不与自身历史版本重复列为主基线。

早期图策略版本用于控制更新方式或状态表示的消融，不能再在主结果表中与本文方法并列作为独立外部方法。若后续取得新的公开方法并完成问题对齐，可在主对比表增加新方法，但需同步说明复现或适配边界。
