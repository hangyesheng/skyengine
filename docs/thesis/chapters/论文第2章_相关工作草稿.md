# 第 2 章 相关工作

## 2.1 制造系统仿真与数字孪生验证

制造数字孪生研究关注物理系统、虚拟模型和数据连接之间的关系。相关综述将制造数字化系统区分为静态数字模型、能够接收物理数据的数字影子以及具有双向交互能力的数字孪生，并强调状态更新、模型校准和闭环决策的重要性。上述研究说明，制造系统仿真不应只停留在几何展示或流程回放，还应支持状态演化、性能分析和调度策略验证。

本文借鉴这一研究路线，但明确平台的证据边界。本文构建的是面向数字孪生验证的柔性制造仿真—调度平台，能够统一建模制造实体、推进仿真时间、执行调度动作、注入动态事件并记录运行过程；当前尚缺少现场传感数据校准和物理产线双向同步证据，因此不将平台表述为完整的物理数字孪生系统。

## 2.2 柔性加工与 AGV 运输协同调度

柔性作业车间调度通常需要同时决定工序顺序和候选机器分配。引入 AGV 后，工序在机器之间的转移也成为影响完工时间的资源约束。机器等待、AGV 可用性、运输距离和路网拥堵会改变工序的实际开始时刻，因此将加工计划与物流计划完全分离可能造成局部最优。

已有研究一类采用数学规划或元启发式方法对加工和运输资源进行统一优化，另一类采用分层或交替策略降低联合动作空间。前者能够表达较完整的耦合约束，但在动态事件和较大实例上求解成本较高；后者更易于在线执行，但需要谨慎处理加工层与运输层之间的信息传递。本文将工序、机器、AGV 和路网关系放入同一个状态表示，并在每次决策中依次确定工序、机器和 AGV。

Moon 等提出的 Heterogeneous Graph Scheduler（HGS）与本文问题结构最为接近。该方法将 operation、machine 和 vehicle 组织为异构关系图，并采用工序—机器—车辆的分阶段解码。本文将 HGS 的核心思想适配到本文仿真平台，用作外部图调度基线。适配实现复用了本文平台的实体模型、路网和执行约束，因而只能称为 HGS 适配实现，不能称为原论文代码的直接复现。

## 2.3 动态事件与在线调度

新作业到达、机器故障、AGV 故障和运输阻塞会改变调度问题的可行域。动态柔性作业车间研究通常通过事件驱动仿真、滚动重调度、规则修复或强化学习处理这些变化。研究对象可能只包含随机作业到达，也可能关注加工设备或运输设备失效，事件定义、可观测信息和终止条件并不统一。

本文将动态适应能力定义为配对评价属性，而不是第二个独立优化目标。对于同一基础实例和同一方法，基准场景不注入外生动态事件，动态事件场景注入预先确定的事件时间线。两种场景使用相同的初始实体配置和评价规则，分别报告 $C_{\max}^{\mathrm{base}}$、$C_{\max}^{\mathrm{event}}$、$\Delta C_{\max}$ 以及 $D_{C_{\max}}$。若事件包含新作业到达，还要报告任务规模变化，避免把新增工作量与故障恢复效应混为一谈。

## 2.4 图神经网络与强化学习调度

调度状态天然包含工序、作业、机器和运输资源之间的关系。图神经网络通过消息传递聚合邻接实体信息，能够表达候选机器能力、工艺先后、作业进度和运输可达性之间的依赖，因而被用于柔性作业车间和组合优化强化学习。相关研究表明，关系图状态有助于应对资源规模变化和复杂候选动作。

强化学习调度方法常采用 PPO、DQN 或 actor—critic 结构。PPO 通过显式价值估计和 clipped objective 稳定策略更新；组相对策略优化方法则利用同组样本的相对回报，减少对价值网络的依赖。本文方法没有价值网络，而是保存决策状态、动态候选集合和轨迹回报，在更新时计算组相对优势，并分别优化工序排序、机器选择和 AGV 选择三个策略头。

需要区分方法思想和工程实现。本文实现包含按单个决策批次分组的更新模式，以及对同一初始实例采样多条独立轨迹的严格组模式。两者都属于本文的组相对优势策略优化实现，不能仅依据实现名称直接称为标准 GRPO。GraphPPO、GraphDP 和 GraphDual 等早期实现用于受控消融或附加分析，不作为本文主方法的外部理论依据。

## 2.5 现有研究的不足与本文定位

已有研究分别为本文提供了四方面基础：数字孪生研究提供了制造系统虚拟建模和闭环验证的概念；加工—运输协同研究说明 AGV 不应被视为事后资源；动态调度研究说明事件发生后需要在线重决策；图强化学习研究说明关系状态适合表达复杂调度约束。

本文关注这些方向之间的连接。具体而言，本文在统一仿真环境中表达作业、工序、机器、AGV 和路网关系，使用动态图状态支持工序—机器—AGV 决策，并用相同实例的基准场景—动态事件场景配对比较方法性能。本文的研究定位是统一建模、在线协同决策和可复现实验验证，而不是提出一个脱离既有调度问题的新问题类别。

## 2.6 本文与相关工作的区别

本文与 HGS 的共同点是都采用工序、机器和运输车辆的结构化决策；区别在于本文进一步建模作业节点、具体工厂路网、机器和 AGV 动态事件，并在统一仿真平台中执行动作。本文与一般图柔性作业车间方法的共同点是使用关系图编码器；区别在于本文把 AGV 运输和路网状态纳入动作链。本文与动态柔性作业车间方法的共同点是关注事件后的持续决策；区别在于本文同时记录事件计划、事件实际执行和配对完工时间差异。

相关论文在其自有数据集上的原始 makespan 数值只用于说明研究背景，不能直接作为本文的实验基线。本文的数值比较只使用在统一仿真平台中重新实现、适配或运行的结果，并明确标注外部方法的适配边界。
